└────────────────────────────────────────────────────────────┘

依赖方向只允许「上 → 下」：L1 可以依赖 L2/L3/L4，反过来不行。代码里到处写的 crate::session、crate::config，真实定义在 L4，靠逐层 pub use 转发到上层。这一层的动机是编译期成本：把最大的 rustc 编译单元拆开，基础层注释原文是「the largest compilation unit (and its peak memory) is roughly halved」jcode-base/src/lib.rs:6。

2. 叶子 crate 家族（83 个子 crate）

家族代表规则
jcode-*-types（数据契约） jcode-session-types、jcode-message-types、jcode-tool-types、jcode-usage-types、jcode-gateway-types、jcode-ambient-types、jcode-memory-types 只放 DTO：serde + 纯函数。禁 IO/网络/进程/TUI/全局状态。只允许依赖外部轻库和兄弟 types crate；scripts/check_dependency_boundaries.py 是守卫CRATE_OWNERSHIP_BOUNDARIES.md:16-27,98-102。
jcode-provider-*（模型适配） jcode-provider-core（Provider trait + 模型表/定价/路由）、jcode-provider-anthropic / -openai / -gemini / -copilot / -bedrock / -openrouter（元数据）、jcode-provider-*-runtime（trait 实现） core 是纯逻辑；runtime 才实现 Provider trait。
jcode-tui-*（UI 组件） jcode-tui-core、-render、-messages、-markdown、-mermaid、-permissions、-tool-display、-session-picker、-usage-overlay、-anim… ratatui 之上的独立 widget，被 L2 组装。
基础设施 jcode-protocol（线协议）、jcode-transport（socket 抽象）、jcode-harness-api(+server)（稳定 API 桥）、jcode-sdk、jcode-storage、jcode-logging、jcode-update-core、jcode-build-*、jcode-command-risk（危险命令判定） 跨层共享的机制，不属于领域行为。

根 crate 之外的非 Rust 代码：telemetry-worker/（TypeScript，Cloudflare）、sdk/typescript/（TS SDK）、ios/（Swift）、crates/jcode-desktop2（桌面壳）。

6. 易错点（指挥 AI 前必读）

  • 没有 attach 子命令。attach 语义由 --resume <id> 承担（TUI 发 Request::Subscribe{target_session_id}）。
  • jcode run 不经 daemon，repl 同理；只有 TUI/connect 路径走 daemon。「所有会话都在 daemon」是错的。
  • types crate 是叶子：让 jcode-session-types 依赖根 crate 会被依赖边界守卫拦下。
  • 四层里的代码到处写 crate::xxx：改基础层模块时，上层通过 re-export 自动可见，但编译成本按层扩散（改 jcode-base 会重编 L3/L2/L1）。
  • jcode-protocol 注释里的 "Agent socket: Inter-agent communication" 疑似遗留：Server::run 只绑 main + debug 两个 socket，agent 间通信走 main socket 的 comm_* 请求。
